## 🌟 ویژگی‌های کلیدی (Key Features)

- 🔄 **پشتیبانی دوگانه از هسته بک‌هال:**
  - **بک‌هال ریورس (Backhaul Reverse):** برقراری اتصال از سرور خارج به سمت سرور ایران؛ پورت‌های ترافیک روی سرور ایران باز شده و از طریق تانل معکوس به خارج هدایت می‌شوند (بهترین حالت جهت دور زدن فیلترینگ شدید).
  - **بک‌هال دایرکت (Backhaul Direct):** برقراری اتصال مستقیم از ایران به خارج.
- 🔑 **معماری اتصال هش‌محور (Hash-based Pairing):**
  - وارد کردن آی‌پی در پنل سرور خارج و کلیک روی «تولید هش اختصاصی تانل».
  - پیست کردن کد `NORA://...` در پنل سرور ایران و برقراری آنی تانل بدون نیاز به پیکربندی دستی فایل‌های کانفیگ!
- 🔌 **مدیریت پورت فورواردینگ (Port Forwarding Management):**
  - افزودن و حذف پورت‌ها با یک کلیک در داشبورد (پشتیبانی از تک پورت مثل `443` یا مپ پورت مثل `8443=443`).
  - کلیدهای سریع پیش‌فرض برای تمام پورت‌های استاندارد Xray و کلودفلر (`443`, `2053`, `2083`, `8080`, `8443`, `2087`, `2096`).
  - اعمال آنی (Live Apply) بدون قطع سشن‌های فعال تانل.
- 🎨 **رابط کاربری فوق‌العاده شکیل (Bespoke Cyberpunk Glassmorphism UI):**
  - طراحی نئون تاریک، بدون باگ، ریسپانسیو برای موبایل و دسکتاپ.
  - نمایش زنده وضعیت اتصال (🟢 متصل / 🟡 در انتظار / 🔴 قطع)، تاخیر رفت و برگشت پکت‌ها (RTT Latency Ping)، مدت زمان آپ‌تایم و لاگ‌های زنده.
- 🚀 **تک‌باینری مستقل (Standalone Binary):**
  - نوشته شده با زبان قدرتمند Go؛ حجم باینری کمتر از ۱۲ مگابایت، مصرف رم کمتر از ۱۵ مگابایت و استارت در ۵ میلی‌ثانیه بدون هیچ وابستگی خارجی.

## 📥 نصب و راه‌اندازی سریع (One-Line Quick Install)

دستور زیر را روی هر دو **سرور خارج** و **سرور ایران** اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NOVA-X-PANEL/NORA-TUNNEL/main/install.sh)
```

پس از اتمام نصب، پنل وب به صورت خودکار روی پورت `7777` در دسترس خواهد بود:
- **نشانی پنل:** `http://SERVER_IP:7777/`
- **نام کاربری پیش‌فرض:** `admin`
- **رمز عبور پیش‌فرض:** `admin`

## 🛠️ راهنمای اتصال گام‌به‌گام (Step-by-Step Connection)

1. **مرحله ۱ (سرور خارج):**
   - وارد پنل وب سرور خارج شوید (`http://KHAREJ_IP:7777`).
   - در تب **راه‌اندازی و اتصال**، آدرس آی‌پی سرور ایران را در کادر `Iran Server Public IP` وارد کنید.
   - حالت تانل را روی **بک‌هال ریورس (Reverse)** بگذارید.
   - پورت‌های مورد نظر را انتخاب و دکمه **تولید هش اختصاصی تانل (Generate Connection Hash)** را بزنید.
   - کد هش تولید شده (با فرمت `NORA://...`) را کپی کنید.

2. **مرحله ۲ (سرور ایران):**
   - وارد پنل وب سرور ایران شوید (`http://IRAN_IP:7777`).
   - در بخش **اتصال سریع با هش**، کد هش کپی شده را پیست کنید.
   - دکمه **اعمال و برقراری آنی تانل (Connect Tunnel)** را کلیک کنید.

3. **مرحله ۳ (برقراری اتصال):**
   - ظرف کمتر از ۱ ثانیه چراغ وضعیت روی هر دو سرور **سبز (متصل و پایدار)** می‌شود و پینگ و تاخیر زنده نمایش داده خواهد شد.
   - تمامی پورت‌های تعیین شده بلافاصله روی آی‌پی ایران فوروارد می‌شوند.

## 💻 دستورات مدیریت خط فرمان (CLI Commands)

اسکریپت دستور اختصاصی `nora` را روی سیستم نصب می‌کند:

```bash
nora start      # استارت سرویس تانل
nora stop       # توقف سرویس تانل
nora restart    # ری‌استارت سرویس تانل
nora status     # مشاهده وضعیت سرویس systemd
nora logs       # مشاهده لاگ‌های زنده
```
